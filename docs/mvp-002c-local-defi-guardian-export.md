# MVP 002C — Local DeFi Guardian Snapshot Export Workflow

This milestone wires an **approved, read-only, local** path from the external
DeFi Guardian analytics project into the Agentic Payments Lab adapter-real-file
demo, using actual sanitized data — without executing any blockchain transaction.

## Exporter boundary

The snapshot is produced by the DeFi Guardian exporter
(`strategy/reports/export_agentic_snapshot.py` in `D:\defi_guardian`), which is
read-only: it reads persisted MongoDB analytics (`position_snapshots`,
`position_valuations`) the same way `report:portfolio` does, never calls RPC,
never writes MongoDB, never launches the watcher, and never signs/broadcasts a
transaction. See `D:\defi_guardian\docs\agentic_snapshot_export.md`.

This repo never reaches into DeFi Guardian internals directly. It only shells
out to the DeFi Guardian package script via a thin wrapper.

## Local runtime path

```text
DeFi Guardian persisted analytics (read-only)
  → export:agentic-snapshot (sanitized)
  → runtime/defi-guardian-snapshots/latest.json   (defi-guardian-snapshot-v1)
  → snapshot:validate:local
  → seller adapter-real-file (DEFI_GUARDIAN_SNAPSHOT_PATH)
  → RiskReport → logs → dashboard
```

The wrapper `tools/export-local-defi-guardian-snapshot.ts` resolves the DeFi
Guardian location from `DEFI_GUARDIAN_ROOT` (Windows default `D:\defi_guardian`)
and writes into this repo's gitignored `runtime/` directory.

## No-commit policy

`runtime/` is gitignored. Actual exported snapshots, runtime logs, and dashboard
exports are **never committed**. Only safe source, docs, `.gitignore`, and
package scripts are committed. `dashboard/index.html` is regenerated by the demo
and is left unstaged unless the canonical public sample is being intentionally
refreshed.

## Actual local validation result

- `snapshot:export:local` → `AGENTIC_SNAPSHOT_EXPORTED`, 4 positions, 4 wallet
  aliases, no raw wallet addresses, no secrets, no RPC, no MongoDB writes, no
  transactions.
- `snapshot:validate:local` → `SNAPSHOT_VALID`, version `defi-guardian-snapshot-v1`,
  4 positions, secrets detected: No.

## adapter-real-file result

`demo:real-local-file` → `REAL_LOCAL_FILE_DEMO_SUCCEEDED`:

- `mode=adapter-real-file`, `adapter.requestedMode=adapter-real-file`,
  `adapter.resolvedMode=adapter-real-file`, `adapter.fallbackUsed=false`,
  `adapter.snapshotVersion=defi-guardian-snapshot-v1`.
- Selected position alias (alias only, never the raw address), selected tokenId,
  risk score, and recommendation are surfaced.
- Seller stopped reliably; port 4021 left with no LISTENING process.

## Demo command

```powershell
cd D:\agentic-payments-lab
npm.cmd run snapshot:export:local      # write runtime/defi-guardian-snapshots/latest.json
npm.cmd run snapshot:validate:local    # validate against defi-guardian-snapshot-v1
npm.cmd run demo:real-local-file        # seller adapter-real-file demo over the local snapshot
```
